# CONTEXT — портфолио WebRunner

Глоссарий домена. Используйте эти термины в коде, issues и тестах.

| Термин | Значение | Не путать / избегать |
|---|---|---|
| **Lang** | Один из 6 поддерживаемых языков: `en` (fallback), `ru`, `kk`, `es`, `de`, `ar` (литературный арабский, MSA — без диалектов и регионов). Всегда первый сегмент URL. | «locale» — не используем; `ar-SA`, `ar-AE` — не используем |
| **Direction** | Направление письма текущего Lang: `rtl` для `ar`, `ltr` для остальных. Определяет зеркалирование раскладки. | |
| **Translation** | Строка `*_translation` с переводимыми полями сущности на конкретном Lang. | |
| **Fallback** | Показ EN-перевода, когда перевода на текущий Lang нет; сопровождается плашкой «доступно на EN». | |
| **Profile** | Данные о владельце: имя, заголовок, о себе, контакты. Телефон в Profile не хранится и публично не показывается. | |
| **Brand** | Публичное имя сайта — **WebRunner** (лого, hero, `<title>`). Реальное имя владельца — только в CV, подзаголовке hero и контактах. | |
| **CV** | Резюме, собранное из Profile и CV-разделов. Две формы: **Web CV** (дизайнерская) и **Print CV** (`/{lang}/cv/print`, A4). | |
| **CV PDF** | PDF, сгенерированный из Print CV через Browser Rendering и сохранённый в R2. | «загруженное резюме» |
| **CV Section** | Раздел CV (Experience, Projects, Technologies, Education, Certifications, Languages) с порядком и флагами `show_web` / `show_pdf`. | |
| **Technology** | Запись справочника технологий (имя, группа, иконка). Раздел CV называется **Technologies**. | «skill», «навык» |
| **Project** | Пет-проект: карточка на странице «Проекты», опционально **Case Study** и попадание в CV (`in_cv`, `cv_bullets`). | |
| **Case Study** | Рассказ о Project в Markdown на его странице `/{lang}/projects/:slug`, свой на каждом Lang. Без него у проекта нет страницы (404). | «кейс» |
| **Featured** | Флаг проекта для показа на главной. | |
| **Post** | Запись блога; статус `draft` / `published`; тело — Markdown. | «статья», «article» |
| **Tag** | Метка поста. | |
| **Album** | Группа фото в галерее. Обложка — одно из его фото; не выбрана — первое по порядку. | |
| **Photo** | Изображение в R2, принадлежит Album, с опциональной переводимой подписью. | |
| **Track** | Аудиотрек плейлиста в R2 с полем источника/лицензии. | |
| **Motion Tier** | Уровень анимации устройства на всю публичную часть, выбирается один раз за визит (ADR-0006, ADR-0012): `full` (слой full поверх `lite`), `lite` (CSS и Web Animations), `static` (конечное состояние; reduced motion). В hero: `full` — Cast Lattice, `lite` — дышащие ромбы лого, `static` — картинка решётки. | «Hero Tier» — прежнее название, в коде до переименования |
| **Слой full** | Код уровня `full`: WebGL-сцены и, если оправдано, библиотеки (ADR-0012). Отдельный чанк, грузится после гейта ввода, вне начального JS и замера Lighthouse. | «база» — это `lite` и `static` |
| **Гейт ввода** | Первый пользовательский ввод на странице (`pointermove`, `pointerdown`, `wheel`, `touchstart`, `keydown`), после которого грузится слой full. `scroll` и `resize` не считаются. | |
| **Cast Lattice** | Эффект слоя full в hero: решётка из литых призм-ромбов на WebGL2, вздымается под указателем, при скролле наклоняется, и семь ромбов лого уходят из неё в хедер. Заменяет Kinetic Grid. | «Kinetic Grid» — прежний эффект на canvas 2D |
| **Admin** | Lazy-маршрут `/admin` за Cloudflare Access. | «CMS», «панель» |
| **Meta Injection** | Подстановка `<title>`/OG/hreflang в HTML на Worker через HTMLRewriter. | «SSR» — у нас его нет |
