# Сайт-портфолио

## 🎯 Цель

Многостраничное личное портфолио WebRunner на домене .dev (не одностраничник). Визуально шедевр анимации, необычный, с ощущением футуризма, но лёгкий и плавный даже на слабом железе.

## 🧱 Стек

- React + Vite + TanStack Router (SPA с маршрутами)
- Tailwind CSS, компоненты shadcn/ui
- Hero: дерзкая анимация из OriginKit
- Анимации: CSS + лёгкая библиотека (GSAP или Motion). Тяжёлые эффекты только в hero, с запасным вариантом для слабых устройств и поддержкой prefers-reduced-motion

## 📄 Страницы

- **Главная / hero**
- **CV**: веб-версия резюме + скачивание PDF
- **Проекты**: доска пет-проектов с фильтрами
- **Галерея**: нужна сразу, на запуске
- **Блог**: посты публикуются из админки
- **Контакты**: почта aibyn_@outlook.com, Telegram @WebRunner_dev, LinkedIn, GitHub WebRunnerDev. Формы связи нет

## 🔐 Админ-панель

- Защищена (например, Cloudflare Access)
- Загрузка фото в галерею и публикация постов в блог
- Опционально: кнопка «поделиться постом в LinkedIn»
- Решено: парсинга LinkedIn нет (официального API нет, это нарушает их правила)

## ✨ Фичи

- Фоновый музыкальный плеер с плейлистом, включается только по клику
- анимации - переходы между стр, на стр, на кнопках, баннерах для переходов и прочем.
- Тёмная и светлая темы
- 5 языков: RU, KK, EN, ES, DE

## ☁️ Инфраструктура (Cloudflare Paid, $5)

- Pages: фронтенд
- Workers: API и админка
- R2: фото и музыка
- D1: метаданные постов, проектов и галереи

## 🎵 Музыка

Плейлист уже есть. Нужны лицензии на использование на сайте: стоки вроде Artlist, Epidemic Sound, Pixabay Music.
