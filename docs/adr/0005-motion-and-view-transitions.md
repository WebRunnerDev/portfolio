# 0005. Motion + View Transitions для анимаций

- Статус: принято; библиотеку Motion заменил ADR-0010 (CSS-анимации), View Transitions в силе
- Дата: 2026-10-14

## Решение
UI- и микроанимации — **Motion** (`motion/react`). Переходы между страницами — нативный **View Transitions API** через поддержку в TanStack Router; в браузерах без поддержки — мгновенный переход. **GSAP** подключается только если понадобятся сложные скролл-сцены — не две библиотеки сразу.

## Последствия
- Минимальный вес и нагрузка на слабые устройства.
- Все анимации обязаны уважать `prefers-reduced-motion`.
