# 0007. Арабский как одна локаль MSA, RTL закладывается с первого дня

- Статус: принято
- Дата: 2026-10-15

## Контекст
Добавлен 6-й язык — арабский, аудитория — страны Залива (Саудовская Аравия, ОАЭ, Катар, Оман). Разговорные диалекты там разные, но письменный веб-контент везде на литературном арабском (MSA). Арабский — RTL; переделка готовой LTR-вёрстки под RTL дорогая, а заложить RTL сразу почти бесплатно.

## Решение
- Одна локаль `ar` (MSA), без региональных вариантов.
- RTL-инфраструктура — в этапе 1, вместе с i18n: shadcn/ui в режиме `--rtl`, `<html dir>` и Radix `DirectionProvider` из одного состояния Lang, только логические Tailwind-классы (линтер `enforce-logical-properties`), инверсия `x` в Motion и свайпах через общий хук направления.
- Не зеркалятся: лого, hero, плеер, блоки кода. Цифры — западные (`ar-u-nu-latn`).
- Арабские переводы — на этапе 6, с вычиткой носителем.

## Альтернативы
- `ar-SA` / `ar-AE` и т.п. — вдвое больше переводов без выгоды для читателя.
- Добавить RTL позже — придётся перепроверять и переписывать каждый компонент.

## Последствия
- Физические классы (`ml-`, `left-`, `text-left`) запрещены линтером с первого коммита.
- Отдельный арабский шрифт, подгружаемый только для `ar`.
- Компоненты OriginKit и Calendar/Pagination/Sidebar из shadcn требуют ручной RTL-проверки.
