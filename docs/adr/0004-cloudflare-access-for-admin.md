# 0004. Админка — lazy-маршрут SPA за Cloudflare Access

- Статус: принято
- Дата: 2026-10-14

## Решение
Админка — маршрут `/admin` того же SPA, загружаемый лениво (не попадает в публичный бандл). **Cloudflare Access** защищает `/admin*` и `/api/admin/*` (вход через GitHub). Worker дополнительно проверяет Access JWT (`Cf-Access-Jwt-Assertion`) на каждом запросе к `/api/admin/*`.

## Последствия
- Нет собственной системы авторизации.
- Для локальной разработки нужен явный dev-обход проверки JWT, недоступный в проде.
