Качество = Chrome «Печать → PDF»: векторный выделяемый текст (ATS-friendly), встроенные шрифты, кликабельные ссылки. Зависит от print-CSS (`@page`, `break-inside: avoid`, ожидание шрифтов). | Q15 | Анимации | ✅ **Motion** (`motion/react`) для UI + **View Transitions API** (через TanStack Router) для переходов между страницами. GSAP — только если понадобятся скролл-сцены. → [ADR-0005](../adr/0005-motion-and-view-transitions.md) |
| Q16 | Hero | ✅ Эффект из OriginKit, заменяемый: компонент за интерфейсом `<Hero tier="full\|lite\|static">`. Три уровня: full (WebGL), lite (CSS/SVG-анимация ромбов лого), static (reduced-motion). Детекция: `prefers-reduced-motion`, `hardwareConcurrency ≤ 4`, `deviceMemory ≤ 4`, `saveData`, FPS-проба 2 с (< 40 → lite). Lazy-load, пауза вне вьюпорта, DPR ≤ 1.5. → [ADR-0006](../adr/0006-hero-tiers.md) |
| Q17 | Айдентика | ✅ Лого есть в SVG (`public/logo.svg`). Палитра есть — проверена (см. Q27). Тема по умолчанию — системная + переключатель. Ромбы — сквозной мотив. Токены фиксируются в `DESIGN.md` через zero-slop-design скиллы. |
| Q18 | Плеер | ✅ Мини-кнопка в углу (ромб-эквалайзер) → панель: play/pause, next/prev, громкость, список треков. Запоминаются громкость и последний трек. Никогда не автоплей. Лёгкий CSS-визуализатор. На мобиле — компактно. |

### Справка: OriginKit
Бесплатная (MIT) библиотека ~50 анимированных React-компонентов от Vellum AI — [originkit.dev](https://www.originkit.dev/), [GitHub](https://github.com/vellum-ai/originkit). Не npm-пакет: исходник кладётся в проект через MCP-плагин или копированием; нужен бесплатный API-ключ (10 загрузок/день). Совместим с React + Vite + Tailwind. Кандидаты для hero: Black Hole, Particle Tunnel, Fluid Trail, Kinetic Grid, Pixel Reveal. Перф-документации и reduced-motion нет — fallback пишем сами.
