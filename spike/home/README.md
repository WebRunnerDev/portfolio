# Прототипы главной (spike, 2026-11-12)

Одноразовые страницы, чтобы выбрать направление главной глазами, а не по описанию. Это не код приложения: свой `package.json`, без FSD, тестов, i18n, Motion Tier и reduced motion, только тёмная тема, контент — заглушки из `shared/content.js`. ESLint их не проверяет.

## Запуск

```sh
cd spike/home
npm install
npm run dev   # http://127.0.0.1:5180/
```

Переключатель прототипов — внизу слева.

## Варианты

| | Идея | Итог |
|---|---|---|
| A · Литьё | Расплав заливают в семь ромбов лого, литые графитовые блоки раскаляются под курсором; блоки ведут главы и собираются в футере | Владельцу понравились структура и блоки, но с ником не связано |
| B · Разгон | Бег по тоннелю ромбических рамок, скорость скролла — скорость бега | — |
| C · Призма | Стеклянный ромб преломляет бренд и раскалывается на семь ромбов | — |
| D · Паутина | Блоки A — узлы сети из расплавленных нитей; краулер обходит паутину, курсор её щиплет | Рекомендован как основа |
| E · Матрица | Литая плита с гравировкой URL и HTTP; бренд залит в буквы-формы | Сильная загрузка, hero перегружен |

Оценка `top-design` на глаз: A 8,2, D 8,4, E 7,5.

## Перед тикетами по D

1. Гасить паутину под текстом ниже hero: нити и узлы — только по краям и между главами.
2. От лого к главам — одна нить для краулера, без пучка у левого края.
3. Из E — живая строка «Crawling · /en/…» в мете hero.

Открыто: как совместить загрузку со сценой и бюджет Lighthouse (JS ≤ 150 KB, LCP ≤ 2,5 с) — решается при переносе в приложение.
