# Прототипы главной (spike, 2026-11-12)

Одноразовые страницы, чтобы выбрать направление главной глазами, а не по описанию. Это не код приложения: свой `package.json`, без FSD, тестов, i18n, Motion Tier и reduced motion, только тёмная тема, контент — заглушки из `shared/content.js`. ESLint их не проверяет.

## Запуск

```sh
cd spike/home
npm install
npm run dev   # http://127.0.0.1:5180/
```

Переключатель прототипов — внизу слева.

## Уровни качества D7

Владелец хочет четыре версии одной сцены: компьютер, компьютер облегчённый, телефон, телефон облегчённый. В D7 это один код с разными числами; панель внизу справа переключает уровень (`?q=desktop | desktop-lite | mobile | mobile-lite`, без параметра — auto) и показывает FPS, число частиц, узлов и нитей.

| Уровень | Частиц на блок | Узлы | Сегменты нити | DPR | Свечение | Пост | Кадры |
|---|---|---|---|---|---|---|---|
| desktop | 9000 | 100 % | 14 | ≤ 1,5 | 0,5 | да | 60 |
| desktop-lite | 4000 | 60 % | 10 | 1 | нет | да | 60 |
| mobile | 4000 | 55 % | 10 | ≤ 1,5 | 0,35 | да | 60 |
| mobile-lite | 1800 | 35 % | 8 | 1 | нет | нет | 30 |

Решение (2026-11-16, на усмотрение агента):
- Телефон или компьютер — по `pointer: coarse` или ширине < 860 px. Слабое устройство (≤ 4 ядер, ≤ 4 ГБ памяти, Save-Data) получает облегчённую сцену, а не сразу CSS-уровень `lite`, как сейчас по ADR-0006.
- Если FPS за окно 2 с ниже 40 (ниже 24 при лимите 30 кадров), сцена на ходу спускается на ступень: меньше частиц (draw range — частицы перемешаны так, что первые k любого узла идут первыми), без свечения, DPR 1, для телефона лимит 30 кадров. Узлы и нити остаются до следующего визита. Ниже облегчённого уровня — CSS `lite` до конца визита. `prefers-reduced-motion` → `static`, как сейчас.
- Касание или клик по паутине: ближайший узел отправляет пакеты по своим нитям — на телефоне это замена курсору.
- При переносе правило ADR-0006 о ядрах и памяти меняется — нужен новый ADR. D7 на three.js (≈ 133 KB) не влезает в потолок full-чанка 30 KB из ADR-0012; металла и PBR в D7 нет, только точки, линии и один проход свечения, поэтому перенос — на голом WebGL2 или OGL.

Посмотреть на телефоне: в `spike/home` запустить `npx vite --port 5181 --host` и открыть адрес из локальной сети.
